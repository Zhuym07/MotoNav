# BOX0 v7.8.15 / MotoNav 8.3.24

日期：2026-10-19。

## 改动

- 手机导航页恢复高德 AMapNaviView 原生面板，移除自定义转向卡片、车速侧栏、渐变遮罩和重复底栏。原生导航视图完整占据自己的布局区域；MotoNav 静音按钮及更快路线提示位于它下方。
- 原因已从旧代码确认：原方案调用 setLayoutVisible(false)，关闭车道/模型路口提示，并在地图上覆盖自绘卡片与底栏；并非仅仅更换了几个按钮。
- 使用 SDK 统一的 setEyrieCrossDisplay(true) 开启路口放大图，替换自 8.1.0 已弃用的旧模型/实景开关；系统栏使用安全边距，避免盖住原生提示。接口核对：高德 AMapNaviViewOptions 官方文档及本项目 10.1.600 JAR 的公开方法。
- 骑行保留 SDK RouteOverLay，使用 SDK 匹配的路段/链接/点进度更新路线。退出和启动失败时释放回调；到达时通知 SDK 清理路线。
- BOX0 普通底图改为按像素中心做双线性采样，减轻旋转时建筑和道路的阶梯边缘。导航路线、文字和箭头在底图之后绘制，不参与平滑。掌机像素主题保留原样。
- 优化相邻四点的打包像素读取，共用地图块地址；正常区域每次只读取 2～4 字节，边界仍按原逻辑读取前一地图块。没有添加地图缓存或修改蓝牙协议。
